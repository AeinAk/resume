# Personal Resume

A simple and responsive personal resume website showcasing my background, skills, experience, and projects.

🌐 **Live Website:** [aeinak.github.io/resume](https://aeinak.github.io/resume/)

## ✨ Features

* Responsive design
* Clean and minimal UI
* Personal profile and contact information
* Skills and technical experience
* Education and professional background
* Projects and relevant experience

* JavaScript
